# Website homepage announces DERT 2027 in Bath

## Summary of the work completed

The website homepage hero is the 2027 event. The title is DERT 2027, the dates are 12th–14th March 2027 in Bath, and the slogan is “Feeling DERTY? It's Bath Time”. The Bath artwork sits on the right. The yellow sticker is visible again and says registration opens on 17th October. The Register button still goes to the dashboard.

## Why the work was completed

DERT 2026 in Birmingham is no longer the event people should see first. Registration for Bath opens on 17th October 2026, so the public homepage needs the new title, dates, slogan, artwork, and an opening date before that day. A new yearly banner follows the existing 2022–2026 components, and the 2026 banner stays in the repo unused.

## Issues that were encountered on the way

The local site stayed on the loading spinner because the API configuration request to `localhost:44100` did not succeed. The compiled homepage module on the running dev server included the new title, dates, slogan, and image. The sticker overlap and the larger date and slogan type were not checked on a rendered page.

## References to any best practices that we found

- [Hide the register sticker and punctuate the app welcome](./2026-09-27-002-homepage-register-sticker.md) — the 2026 sticker was hidden in CSS until the next event. This banner shows the sticker again for 2027.

## Any remaining issues that we may wish to address
