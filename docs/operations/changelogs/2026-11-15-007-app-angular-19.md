# App upgraded from Angular 18 to Angular 19

## Summary of the work completed

The app (`apps/dert-app`) now builds and runs on Angular **19.2.25**, CLI **19.2.27**, and TypeScript **5.8.3**. Ionic stays on 8, at **8.8.19**. RxJS stays **7.8.2**. `zone.js` is **0.15.1**. Node stays **18.20.8**. `npm install` in `apps/dert-app/src/client` succeeds without `force`. `npm run build:hosted` succeeds. The app smoke suite passed.

The optional `use-application-builder` and `provide-initializer` migrations were not run. The webpack `browser` builder stayed. `APP_INITIALIZER` stayed. The required migration added `standalone: false` to 25 components, directives, and pipes. The Protractor builder is still in the CLI package, so the `e2e` target stayed. `target` stayed `es2020`. Auth0 login was not rewritten.

This hop is branched from `feature/app-angular-18`. Notes are in [Upgrading Angular](../../technical/guides/upgrading-angular.md).

## Why the work was completed

This is the sixth hop from Angular 13 toward the website's Angular 22. Angular 19 defaults new components to standalone. The required migration marks the existing NgModule classes `standalone: false`, so the app keeps today's modules. Ionic **8.8.19** already peers Angular `>=16`, so Ionic stayed.

## Issues that were encountered on the way

- `ng update @angular/cli@^19 @angular/core@^19` completed with `--allow-dirty` and no `--force`. It moved TypeScript from **5.4.5** to **5.8.3** and `zone.js` from **0.14.10** to **0.15.1**.
- `npm install` warned that optional peer `karma` `^6.4.0` from `@angular/build` was overridden by the installed `karma` 6.3. The install did not fail. Karma stayed at **6.3.16**.
- The production build warns that Sass `@import` is deprecated. The styles were not rewritten.
- The initial bundle is **2.27 MB**. The 2 MB warning budget is exceeded by about 275 kB. The build exits 0.
- The Protractor builder is still present under `@angular-devkit/build-angular`, so it was not removed from `angular.json`.

## References to any best practices that we found

- [Angular version compatibility](https://angular.dev/reference/versions) — Angular 19.2 supports Node `^18.19.1 || ^20.11.1 || ^22.0.0`, TypeScript `>=5.5.0 <5.9.0`, and RxJS `^6.5.3 || ^7.4.0`. The installed CLI engines field is `^18.19.1 || ^20.11.1 || >=22.0.0`.
- [Ionic support policy](https://ionicframework.com/docs/reference/support) — Ionic 8 supports Angular 16 through 20. This hop stayed on **8.8.19**.
- [Upgrading Angular](../../technical/guides/upgrading-angular.md) — the website kept the webpack builder on this hop and let the core migration set `standalone: false`.
