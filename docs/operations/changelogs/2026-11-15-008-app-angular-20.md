# App upgraded from Angular 19 to Angular 20

## Summary of the work completed

The app (`apps/dert-app`) now builds and runs on Angular **20.3.35**, CLI **20.3.43**, and TypeScript **5.8.3**. Ionic stays on 8, at **8.8.19**. RxJS stays **7.8.2**. `zone.js` stays **0.15.1**. Node moved from **18.20.8** to **20.20.2**. `npm install` in `apps/dert-app/src/client` succeeds without `force`. `npm run build:hosted` succeeds. The app smoke suite passed.

One stop was cleared while the app was still on Angular 19.2.25. App CI and the app Docker image moved from Node 18 to Node 20. Node 20.20.2 is inside both the Angular 19.2 range (`^20.11.1`) and the Angular 20 range (`^20.19.0`). The production build and the smoke suite passed on Angular 19 before `ng update`.

The optional `use-application-builder`, `control-flow-migration`, and `router-current-navigation` migrations were not run. The webpack `browser` builder stayed. `*ngIf`, `*ngFor`, and `*ngSwitch` stayed. `APP_INITIALIZER` stayed. The `standalone: false` flags from the Angular 19 hop stayed. A required CLI migration set `moduleResolution` to `bundler` and wrote schematic defaults that keep the current file-name suffixes. The Protractor builder is still in the CLI package, so the `e2e` target stayed. `target` stayed `es2020`. Auth0 login was not rewritten.

This hop is branched from `feature/app-angular-19`. Notes are in [Upgrading Angular](../../technical/guides/upgrading-angular.md).

## Why the work was completed

This is the seventh hop from Angular 13 toward the website's Angular 22. Angular 20 does not run on Node 18. Node 20 is still inside the Angular 19 range, so the app moved to Node 20 before the framework moved. Ionic **8.8.19** already peers Angular `>=16`, and the support policy lists Ionic 8 through Angular 20, so Ionic stayed.

## Issues that were encountered on the way

- App CI (`app-src-ci.yml`, `app-src-cd.yml`) and the app image moved to Node 20 while the app was still on Angular 19.2.25. `npm install` on Node **20.20.2** (npm 10.8.2) left `lockfileVersion` 3. The production build hash matched the Angular 19 build from Node 18 (`8c24faff8c75617c`).
- The first smoke run after that Node move failed once: Send Scores stayed disabled after an out-of-range score was corrected. The same suite passed on the immediate retry, before `ng update`. The Angular 20 suite then passed on the first run.
- `ng update @angular/cli@^20 @angular/core@^20` completed with `--allow-dirty` and no `--force`. It left TypeScript at **5.8.3** and `zone.js` at **0.15.1**. CLI **20.3.43**, framework **20.3.35**.
- `npm install` warned that optional peer `karma` `^6.4.0` from `@angular/build` was overridden by the installed `karma` 6.3. The install did not fail. Karma stayed at **6.3.16**.
- The CLI migration set `tsconfig.json` `moduleResolution` from `node` to `bundler` and added `type` / `typeSeparator` schematic defaults in `angular.json`. `target` stayed `es2020`. The `DOCUMENT`, `InjectFlags`, and `TestBed.get` migrations made no changes.
- The production build warns that Sass `@import` is deprecated. The styles were not rewritten.
- The initial bundle is **2.38 MB**. The 2 MB warning budget is exceeded by about 377 kB. The build exits 0.
- The Protractor builder is still present under `@angular-devkit/build-angular`, so it was not removed from `angular.json`.

## References to any best practices that we found

- [Angular version compatibility](https://angular.dev/reference/versions) — Angular 20.3 supports Node `^20.19.0 || ^22.12.0 || ^24.0.0`, TypeScript `>=5.8.0 <6.0.0`, and RxJS `^6.5.3 || ^7.4.0`. The installed CLI engines field is `^20.19.0 || ^22.12.0 || >=24.0.0`.
- [Angular v20](https://github.com/angular/angular/releases/tag/20.0.0) — Node 18 is removed. `*ngIf`, `*ngFor`, and `*ngSwitch` are deprecated. `DOCUMENT` moves from `@angular/common` to `@angular/core`.
- [Ionic support policy](https://ionicframework.com/docs/reference/support) — Ionic 8 supports Angular 16 through 20. This hop stayed on **8.8.19**.
- [Migrating to the new build system](https://angular.dev/tools/cli/build-system-migration) — the application builder migration is still optional. This hop kept the webpack `browser` builder.
- [Node.js 20.20.2](https://nodejs.org/en/blog/release/v20.20.2) is the last Node 20 release. The 20 line ended on 30 April 2026.
- [Upgrading Angular](../../technical/guides/upgrading-angular.md) — the website moved to Node 20 before `ng update` on this same hop and left the control-flow migration unrun.

Node **20.20.2** is inside the Angular 21 range (`^20.19.0 || ^22.12.0 || ^24.0.0`). TypeScript **5.8.3** is not. Angular 21 needs TypeScript `>=5.9.0`. Let `ng update` move it.
- Karma **6.3.16** is below the optional `@angular/build` peer `^6.4.0`. The unit-test script is not the check for this hop.
- The Dockerfile still runs `npm install --force`. The app install on the host does not need it.
- The Protractor target is still configured. The Playwright suite is the check that matters.
- `*ngIf`, `*ngFor`, and `*ngSwitch` are deprecated and still compile. The control-flow migration was offered and not run.
- Auth0 login is still `auth0-js` and `@auth0/angular-jwt`. Sharing that login with the website is later work.
