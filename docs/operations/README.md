# Operations

Operational knowledge for this repository: what we planned, investigated, and completed while working in the solution.

**Not a ticket system.** [GitHub Issues](https://github.com/dertinfo/dertinfo-mono/issues) track work. These folders hold durable notes that stay next to the code. When a discussion identifies new work, open an issue. Do not add a backlog page here.

| Folder | Purpose |
|--------|---------|
| [changelogs/](changelogs/) | Completed workstreams (outcome, issues, practices, follow-ups) |
| [investigations/](investigations/) | Resolved or historical deep-dives (symptoms, root cause, resolution) |
| [security/](security/) | Point-in-time security reviews of how we operate the repo and cloud estate |
| [agents/](agents/) | How AI agents should maintain this documentation library |

See also: [Documentation guide](../documentation-guide.md).
