# Entity: Dert of Derts submission

## Description

A [group](group.md)'s dance video in the Dert of Derts programme. The public can watch it and score it. The programme is separate from event registration, venue score capture, and competition results. See [Dert of Derts](../features/web/dod-programme.md).

## What can be done

- **Submit** — a group, as the programme allows. The submission carries the video and where and when the dance is from.
- **Watch** — public-user.
- **Score** — a participant in the programme. Each set of marks is a [Dert of Derts result](dod-result.md).
- **Administer** — dod-admin. Manage submissions for the programme.

This entity has no lifecycle states.
