# Feature: Dert of Derts (DoD)

## Description

An online programme related to the same dance tradition: the public can view uploaded team videos and score / give feedback against marking criteria. Administratively separate from core Dert event and venue scoring.

## User roles

- **public-user** / signed-in participants — view and participate in public DoD flows as the product allows (judging, results, talks, how-to)
- **dod-admin** — administer DoD submissions, judges, scorecards, talks, settings, complaints as applicable

## Behaviour

- Teams upload videos; the public can watch and score against marking criteria.
- DoD admin manages the programme areas needed to run that online offering.

## Limitations

- Isolated from core event registration, venue score capture, and competition publish flows described elsewhere.
- Does not replace on-the-day Dert venue judging.
